# #407 CoPE-B-S1 Eval with Explainable Reasons — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add two eval models, `s1-master` and `s1-bundle`, that call Zentropi's hosted CoPE-B-S1 multilabel API. Let Bryan tick reason families on toxic labels, and report how well S1's reasons match his.

**Architecture:** One new eval-only HTTP client (`s1.rs`) sends the master policy, plus the six reason policies in bundle mode, as one `/v1/multilabel` request per post. The master answer becomes the normal `ClassifierVerdict`. The reasons are stashed in the client and collected by the runner through a small `ReasonSource` trait, then saved on the existing `VerdictRecord`. Labels gain an optional `reasons` list. A new `reason_report.rs` computes the reason metrics shown under the existing report.

**Tech Stack:** Rust; `reqwest` 0.12, `serde`/`serde_json`, `tokio`, `anyhow`; `wiremock` 0.6 (dev) for HTTP tests.

**Spec:** `docs/superpowers/specs/2026-10-22-407-cope-b-s1-policy-decomposition-design.md`. Chainlink #407. Branch `feat/407-cope-b-s1-design`.

## Deviations from the spec (decided while planning)

1. **The client lives at `src/cli/eval_classifiers/s1.rs`**, not `src/toxicity/zentropi_multilabel.rs`. It is eval-only, and putting it under `toxicity` would make that module depend on the eval's hashing and reason types. Phase 2 (production) would move it.
2. **No "wrong model echoed" check.** The hosted response does not echo the model. Identity is what the client declares (model `cope-b-s1`, plus a policy version), as for Detoxify.
3. **No cache-key code change.** The cache already keys on `policy_version`. S1's policy version is a hash of every policy it sends, so editing a reason file re-judges `s1-bundle` only, and `s1-master` is untouched.
4. **Policies are compiled in** with `include_str!`. Editing a reason file takes effect on the next `cargo run`, which rebuilds.

```rust
//! Reason families for explainable flags (#407).
//!
//! The master policy alone decides toxic or clean. These six families only
//! explain a flag the master already made, so the protected user can see WHY.
//! They are distinct concepts on purpose: Zentropi's S1 model card warns that
//! bundling overlapping shades of one concept costs accuracy.

use anyhow::{bail, Result};
use serde::{Deserialize, Serialize};
use std::collections::BTreeMap;

/// Every reason family, in display order. Labels, verdicts and the report
/// all use exactly these keys.
pub const REASON_KEYS: [&str; 6] = [
    "personal_attack",
    "identity_hate",
    "mockery",
    "threat",
    "pile_on",
    "bad_faith",
];

/// One family's answer for one post.
#[derive(Debug, Clone, Copy, PartialEq, Serialize, Deserialize)]
pub struct ReasonAnswer {
    pub fired: bool,
    /// The hosted API's confidence in its own answer (0.5–1.0), not P(true).
    pub confidence: f32,
}

/// The reason answers for one post.
#[derive(Debug, Clone, PartialEq, Serialize, Deserialize)]
pub struct ReasonSet {
    pub answers: BTreeMap<String, ReasonAnswer>,
    /// False when any family was missing or garbled in the response. The
    /// master verdict is still kept; the report leaves incomplete sets out of
    /// its reason rates rather than counting a missing answer as "no".
    pub complete: bool,
}

impl ReasonSet {
    /// The families that said yes, in [`REASON_KEYS`] order.
    pub fn fired(&self) -> Vec<&'static str> {
        REASON_KEYS
            .iter()
            .copied()
            .filter(|k| self.answers.get(*k).is_some_and(|a| a.fired))
            .collect()
    }

    /// The most confident family that said yes. Ties go to the earlier
    /// family in [`REASON_KEYS`], so the answer never depends on map order.
    pub fn top(&self) -> Option<&'static str> {
        let mut best: Option<(&'static str, f32)> = None;
        for k in self.fired() {
            let c = self.answers[k].confidence;
            if best.is_none_or(|(_, b)| c > b) {
                best = Some((k, c));
            }
        }
        best.map(|(k, _)| k)
    }
}

/// A classifier that can also say which reasons it found. Kept apart from
/// `ToxicityClassifier` so production's trait is untouched: the eval runner
/// asks for reasons right after each verdict and saves them alongside.
pub trait ReasonSource: Send + Sync {
    /// The reasons recorded for the latest answer on exactly this text,
    /// removed so the store does not grow over a run.
    fn take_reasons(&self, content: &str) -> Option<ReasonSet>;
}

/// Refuse unknown or repeated reason keys, naming the valid ones, so a typo
/// in a hand-edited label is caught instead of silently never matching.
pub fn check_reason_keys(keys: &[String]) -> Result<()> {
    let mut seen = std::collections::HashSet::new();
    for k in keys {
        if !REASON_KEYS.contains(&k.as_str()) {
            bail!("unknown reason {k:?} (valid: {})", REASON_KEYS.join(", "));
        }
        if !seen.insert(k.as_str()) {
            bail!("reason {k:?} is listed twice");
        }
    }
    Ok(())
}
```

```rust
//! Zentropi's hosted CoPE-B-S1 multilabel API, for the eval only (#407).
//!
//! One request per post asks several yes/no policy questions at once. The
//! `master` question (Bryan's whole policy, unchanged) is the verdict; in
//! bundle mode six reason questions ride along to explain it. The hosted API
//! returns a 0/1 label plus a confidence per question — not the raw
//! probability — which is enough to compare models, not to tune thresholds.
//!
//! Parsing is strict because the API is a preview whose "specs may change":
//! a missing or odd field is an error, never a quiet "no".

use anyhow::{bail, Context, Result};
use serde::Deserialize;
use std::collections::{BTreeMap, HashMap};
use std::sync::{LazyLock, Mutex, PoisonError};
use std::time::{Duration, Instant};

use super::content_hash;
use super::reasons::{ReasonAnswer, ReasonSet, ReasonSource, REASON_KEYS};
use crate::toxicity::classifier::{ClassifierVerdict, ToxicityClassifier};

pub const S1_API_URL: &str = "https://api.zentropi.ai/v1/multilabel";

#[derive(Debug, Clone, Copy, PartialEq, Eq)]
pub enum S1Mode {
    /// The master policy alone: the model card's most accurate mode.
    Master,
    /// Master plus the six reasons in one request.
    Bundle,
}

/// A stable version for a set of (key, policy) pairs. Any change to any
/// text or key changes it, which is what makes the verdict cache re-judge.
fn version_of(labelers: &[(&str, &str)]) -> String {
    let mut s = String::new();
    for (k, t) in labelers {
        s.push_str(k);
        s.push('\0');
        s.push_str(t);
        s.push('\0');
    }
    format!("s1-{}", content_hash(&s))
}

static MASTER_VERSION: LazyLock<String> =
    LazyLock::new(|| version_of(&S1Mode::Master.labelers()));
static BUNDLE_VERSION: LazyLock<String> =
    LazyLock::new(|| version_of(&S1Mode::Bundle.labelers()));

impl S1Mode {
    /// (key, policy text) for every question this mode asks, master first.
    pub fn labelers(self) -> Vec<(&'static str, &'static str)> {
        let mut v = vec![(MASTER_KEY, MASTER_POLICY)];
        if self == S1Mode::Bundle {
            v.extend(REASON_POLICIES);
        }
        v
    }

    /// `&'static` because `ToxicityClassifier::policy_version` requires it;
    /// a `LazyLock` static computes each once instead of leaking per client.
    pub fn policy_version(self) -> &'static str {
        match self {
            S1Mode::Master => MASTER_VERSION.as_str(),
            S1Mode::Bundle => BUNDLE_VERSION.as_str(),
        }
    }

    pub fn eval_name(self) -> &'static str {
        match self {
            S1Mode::Master => "s1-master",
            S1Mode::Bundle => "s1-bundle",
        }
    }
}

pub fn build_request(mode: S1Mode, content: &str) -> serde_json::Value {
    let labelers: Vec<serde_json::Value> = mode
        .labelers()
        .into_iter()
        .map(|(key, text)| serde_json::json!({"key": key, "criteria_text": text}))
        .collect();
    serde_json::json!({
        "model": S1_MODEL_ID,
        "content_text": content,
        "labelers": labelers,
    })
}

/// One item of the response array. Fields are Options so a missing one
/// is reported by us, per key, instead of failing the whole array decode.
#[derive(Deserialize)]
struct Item {
    key: Option<String>,
    label: Option<String>,
    confidence: Option<f64>,
}

/// The decoded answer to one post.
#[derive(Debug, Clone, PartialEq)]
pub struct Parsed {
    pub toxic: bool,
    pub confidence: f32,
    /// `None` in master mode.
    pub reasons: Option<ReasonSet>,
}

fn decode(item: &Item) -> Result<(bool, f32)> {
    let fired = match item.label.as_deref() {
        Some("1") => true,
        Some("0") => false,
        other => bail!("label {other:?} is not \"0\" or \"1\""),
    };
    let c = item.confidence.context("confidence missing")?;
    if !(c.is_finite() && (0.0..=1.0).contains(&c)) {
        bail!("confidence {c} is outside 0–1");
    }
    Ok((fired, c as f32))
}

pub fn parse_response(mode: S1Mode, body: &str) -> Result<Parsed> {
    let items: Vec<Item> =
        serde_json::from_str(body).context("S1 response is not the documented array")?;
    let allowed: Vec<&str> = mode.labelers().into_iter().map(|(k, _)| k).collect();
    let mut by_key: HashMap<String, Item> = HashMap::new();
    for item in items {
        let key = item.key.clone().context("S1 response item without a key")?;
        if !allowed.contains(&key.as_str()) {
            bail!("S1 response has unexpected key {key:?}");
        }
        if by_key.insert(key.clone(), item).is_some() {
            bail!("S1 response repeats key {key:?}");
        }
    }
    let master = by_key
        .get(MASTER_KEY)
        .context("S1 response has no master answer")?;
    let (toxic, confidence) = decode(master).context("S1 master answer")?;
    let reasons = (mode == S1Mode::Bundle).then(|| {
        let mut answers = BTreeMap::new();
        let mut complete = true;
        for k in REASON_KEYS {
            // A bad reason never sinks the verdict: keep the master, and let
            // the report leave this post out of its reason rates.
            match by_key.get(k).map(decode) {
                Some(Ok((fired, confidence))) => {
                    answers.insert(k.to_string(), ReasonAnswer { fired, confidence });
                }
                _ => complete = false,
            }
        }
        ReasonSet { answers, complete }
    });
    Ok(Parsed { toxic, confidence, reasons })
}

/// Whether a failed attempt is worth repeating.
enum Attempt {
    Retry(anyhow::Error),
    Fatal(anyhow::Error),
}

pub struct S1Client {
    http: reqwest::Client,
    api_key: String,
    api_url: String,
    mode: S1Mode,
    initial_backoff: Duration,
    /// Reasons from each answered post, keyed by its exact text, until the
    /// runner takes them (see [`ReasonSource`]).
    reasons: Mutex<HashMap<String, ReasonSet>>,
}

impl S1Client {
    pub fn new(api_key: String, mode: S1Mode) -> Result<Self> {
        Self::with_api_url(api_key, mode, S1_API_URL.to_string())
    }

    /// The endpoint injected, so tests can point at a local mock server.
    pub fn with_api_url(api_key: String, mode: S1Mode, api_url: String) -> Result<Self> {
        if api_key.trim().is_empty() {
            bail!("ZENTROPI_API_KEY is empty");
        }
        let http = reqwest::Client::builder()
            .timeout(REQUEST_TIMEOUT)
            .build()
            .context("building the S1 HTTP client")?;
        Ok(Self {
            http,
            api_key,
            api_url,
            mode,
            initial_backoff: INITIAL_BACKOFF,
            reasons: Mutex::new(HashMap::new()),
        })
    }

    /// Shorter waits for tests; production keeps 500 ms doubling.
    pub fn with_backoff(mut self, initial: Duration) -> Self {
        self.initial_backoff = initial;
        self
    }

    async fn send_once(&self, content: &str) -> std::result::Result<String, Attempt> {
        let resp = self
            .http
            .post(&self.api_url)
            .bearer_auth(&self.api_key)
            .json(&build_request(self.mode, content))
            .send()
            .await
            .map_err(|e| Attempt::Retry(anyhow::Error::new(e).context("reaching the S1 API")))?;
        let status = resp.status();
        let body = resp.text().await.unwrap_or_default();
        if status.is_success() {
            return Ok(body);
        }
        let err = anyhow::anyhow!("S1 API error {status}: {body}");
        if status.as_u16() == 429 || status.is_server_error() {
            Err(Attempt::Retry(err))
        } else {
            Err(Attempt::Fatal(err))
        }
    }

    async fn call(&self, content: &str) -> Result<Parsed> {
        let mut backoff = self.initial_backoff;
        let mut attempt = 0;
        let body = loop {
            match self.send_once(content).await {
                Ok(body) => break body,
                Err(Attempt::Retry(e)) if attempt < MAX_RETRIES => {
                    attempt += 1;
                    tracing::debug!(attempt, error = %e, "S1 retry");
                    tokio::time::sleep(backoff).await;
                    backoff *= 2;
                }
                Err(Attempt::Retry(e)) | Err(Attempt::Fatal(e)) => return Err(e),
            }
        };
        // A shape error is not retried: the same request gets the same shape.
        parse_response(self.mode, &body)
    }
}

#[async_trait::async_trait]
impl ToxicityClassifier for S1Client {
    async fn classify(&self, content: &str) -> Result<ClassifierVerdict> {
        let start = Instant::now();
        let parsed = self.call(content).await?;
        if let Some(r) = parsed.reasons {
            self.reasons
                .lock()
                .unwrap_or_else(PoisonError::into_inner)
                .insert(content.to_string(), r);
        }
        Ok(ClassifierVerdict {
            toxic_token: parsed.toxic,
            confidence: parsed.confidence,
            latency_ms: start.elapsed().as_millis().try_into().unwrap_or(u32::MAX),
            model_id: S1_MODEL_ID.to_string(),
            policy_version: self.policy_version().to_string(),
        })
    }
    fn name(&self) -> &'static str {
        self.mode.eval_name()
    }
    fn model_id(&self) -> &'static str {
        S1_MODEL_ID
    }
    fn policy_version(&self) -> &'static str {
        self.mode.policy_version()
    }
    /// The hosted API already decided 0/1; take its answer as given.
    fn threshold(&self) -> f32 {
        0.0
    }
}

impl ReasonSource for S1Client {
    fn take_reasons(&self, content: &str) -> Option<ReasonSet> {
        self.reasons
            .lock()
            .unwrap_or_else(PoisonError::into_inner)
            .remove(content)
    }
}
```

```rust
/// Each post's ticked reasons, from the newest label row whose hash matches
/// the post's present text — the same rule [`load_current_labels`] uses, so
/// reasons never outlive the answer they belong to. Only posts with at least
/// one reason are returned. A hand-edited bad reason is an error naming the
/// line: silently skipping it would score a family on missing data.
pub fn load_current_reasons(path: &Path, pool: &[FixtureRow]) -> Result<HashMap<String, Vec<String>>> {
    let present: HashMap<&str, String> = pool
        .iter()
        .map(|r| (r.id.as_str(), content_hash(&r.content)))
        .collect();
    let text = match std::fs::read_to_string(path) {
        Ok(t) => t,
        Err(e) if e.kind() == std::io::ErrorKind::NotFound => return Ok(HashMap::new()),
        Err(e) => return Err(e).with_context(|| format!("reading {}", path.display())),
    };
    let mut out = HashMap::new();
    for (i, l) in text.lines().filter(|l| !l.trim().is_empty()).enumerate() {
        let at = format!("{} line {}", path.display(), i + 1);
        let label: Label = serde_json::from_str(l).with_context(|| at.clone())?;
        if !label.reasons.is_empty() && label.label != Truth::Toxic {
            bail!("{at}: reasons are only for toxic labels");
        }
        super::reasons::check_reason_keys(&label.reasons).with_context(|| at.clone())?;
        if present.get(label.id.as_str()) == Some(&label.content_hash) {
            // Newest matching row wins, as for the answer itself.
            if label.reasons.is_empty() {
                out.remove(&label.id);
            } else {
                out.insert(label.id, label.reasons);
            }
        }
    }
    Ok(out)
}
```

```rust
//! How well S1's reasons explain its flags (#407, spec §6). Holdout only,
//! like the headline: diagnostic and seed posts were picked by hand or by
//! model behaviour and would bias these rates.

use std::collections::HashMap;
use std::fmt::Write;

use super::cache::VerdictRecord;
use super::data::{Answer, Source, Truth};
use super::metrics::Rate;
use super::reasons::REASON_KEYS;
use super::report::rate_cell;

/// Below this many ticked posts a family's rate is noise, so none is shown.
pub const MIN_TICKED: u32 = 10;

#[derive(Debug, Clone, PartialEq, Default)]
pub struct FamilyStats {
    pub key: &'static str,
    /// Of posts where Bryan ticked this family: how often S1 said yes.
    pub when_ticked: Rate,
    /// Of posts where he ticked others but not this one: how often S1 said yes.
    pub when_not_ticked: Rate,
    /// Posts the master called clean where this family still fired.
    pub on_clean_calls: u32,
}

#[derive(Debug, Clone, PartialEq, Default)]
pub struct ReasonStats {
    pub flagged: u32,
    /// Flagged with no reason: what the protected user would see as
    /// "flagged under your overall policy; no specific reason matched".
    pub unexplained: u32,
    pub clean_calls: u32,
    /// A high count means some reason policy is broader than the master.
    pub clean_with_reasons: u32,
    pub incomplete: u32,
    pub top_agree: Rate,
    pub families: Vec<FamilyStats>,
}

pub fn reason_stats(
    verdicts: &HashMap<String, VerdictRecord>,
    answers: &HashMap<String, Answer>,
    ticked: &HashMap<String, Vec<String>>,
) -> ReasonStats {
    let mut s = ReasonStats {
        families: REASON_KEYS
            .iter()
            .map(|k| FamilyStats { key: k, ..FamilyStats::default() })
            .collect(),
        ..ReasonStats::default()
    };
    for (id, rec) in verdicts {
        let Some(answer) = answers.get(id).filter(|a| a.source == Source::Holdout) else {
            continue;
        };
        let (Some(called), Some(set)) = (rec.called_toxic, rec.reasons.as_ref()) else {
            continue;
        };
        if !set.complete {
            s.incomplete += 1;
            continue;
        }
        let fired = set.fired();
        if called {
            s.flagged += 1;
            if fired.is_empty() {
                s.unexplained += 1;
            }
        } else {
            s.clean_calls += 1;
            if !fired.is_empty() {
                s.clean_with_reasons += 1;
            }
            for f in s.families.iter_mut().filter(|f| fired.contains(&f.key)) {
                f.on_clean_calls += 1;
            }
        }
        let Some(ticks) = ticked.get(id).filter(|t| !t.is_empty()) else {
            continue;
        };
        if answer.truth != Truth::Toxic {
            continue;
        }
        for f in &mut s.families {
            let rate = if ticks.iter().any(|t| t == f.key) {
                &mut f.when_ticked
            } else {
                &mut f.when_not_ticked
            };
            rate.n += 1;
            if fired.contains(&f.key) {
                rate.hits += 1;
            }
        }
        if let Some(top) = set.top() {
            s.top_agree.n += 1;
            if ticks.iter().any(|t| t == top) {
                s.top_agree.hits += 1;
            }
        }
    }
    s
}

pub fn render_reasons(model: &str, s: &ReasonStats) -> String {
    let mut out = String::new();
    let _ = writeln!(out, "\nREASONS — {model}, holdout posts");
    let _ = writeln!(out, "  flagged with no reason: {} of {}", s.unexplained, s.flagged);
    let _ = writeln!(
        out,
        "  clean calls where a reason still fired: {} of {}",
        s.clean_with_reasons, s.clean_calls
    );
    let _ = writeln!(out, "  left out (incomplete reasons): {}", s.incomplete);
    let _ = writeln!(out, "  top reason is one you ticked: {}", rate_cell(&s.top_agree));
    let _ = writeln!(
        out,
        "  {:<16} {:<28} {:<28} {:>9}",
        "family", "fired when you ticked it", "fired when you didn't", "on clean"
    );
    for f in &s.families {
        if f.when_ticked.n < MIN_TICKED {
            let _ = writeln!(
                out,
                "  {:<16} too few examples ({} < {MIN_TICKED}) {:>40}",
                f.key, f.when_ticked.n, f.on_clean_calls
            );
            continue;
        }
        let _ = writeln!(
            out,
            "  {:<16} {:<28} {:<28} {:>9}",
            f.key,
            rate_cell(&f.when_ticked),
            rate_cell(&f.when_not_ticked),
            f.on_clean_calls
        );
    }
    out
}
```
